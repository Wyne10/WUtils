# WUtils Documentation

WUtils is a multi-module collection of independently versioned and
independently published Java/Kotlin libraries for Bukkit/Paper 1.16.5
plugins; each module is its own Maven Central artifact and consumers pull
only the modules they need. This wiki documents WUtils module by module,
package by package, for a developer who already knows Bukkit/Paper but has
never seen this codebase. It currently covers the `animation`, `common`,
`commonKt`, `config`, `configurables`, `i18n`, `i18nKt`, `jdbc`, `json` and `structure`
modules; the project-wide overview is added as it is documented. The deprecated `log`
module is excluded from the build and is not documented.
