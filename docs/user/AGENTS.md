# WUtils User Documentation

WUtils is a collection of independently published Java/Kotlin libraries for Bukkit/Paper
1.16.5 plugins. Each module is its own Maven Central artifact under the group
`io.github.wyne10`, so you depend only on the parts you actually use — WUtils is not a
framework and there is nothing to install on the server.

This is the **user wiki**: how to add a module to your build, what it gives you, and what
to watch out for, with examples. Start with [Getting Started](getting-started.md).

If you are changing WUtils itself rather than using it, read the
[contributor wiki](../dev/AGENTS.md) instead — it covers the same ground at the level of
internals, invariants and source locations.
